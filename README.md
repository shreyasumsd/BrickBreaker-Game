🧱 Brick Breaker Game

A simple and interactive Brick Breaker Game built using HTML, CSS, and JavaScript.
The game demonstrates core concepts of game logic, DOM manipulation, and collision detection using vanilla JavaScript.

🎮 Gameplay Overview

Control the paddle to bounce the ball

Break all the bricks to win

Avoid letting the ball fall below the paddle

Smooth animations and real-time collision handling

🛠️ Tech Stack

HTML5 – Game structure

CSS3 – Styling and layout

JavaScript (Vanilla) – Game logic and interactions

📁 Project Structure
BrickBreaker-Game/
│
├── index.html    # Main HTML file
├── style.css     # Game styling
└── script.js     # Game logic and mechanics

🚀 How to Run the Game

Clone the repository:

git clone https://github.com/shreyasumsd/BrickBreaker-Game.git


Navigate to the project folder:

cd BrickBreaker-Game/brick


Open index.html in any modern browser
(Chrome, Edge, Firefox recommended)
